# Willa (Xiaoyi Wang) 个人网站

## 直接使用
解压后用 Chrome、Edge、Safari 或 Firefox 打开 index.html，无需安装依赖。请保留 index.html、style.css、script.js 与 assets 文件夹之间的相对位置。
网站未部署到互联网。需要上线时，将整个文件夹上传到静态网站托管服务即可。
